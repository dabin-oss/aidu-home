Token Architecture
토큰 구조 원칙
2단 구조를 따른다. 화면을 그릴 때는 semantic만 사용한다. primitive를 직접 쓰지 않는다.
01 · Primitive
indigo-500 = #4F5BD5
순수한 값. 의미 없음. 팔레트 그 자체.
02 · Semantic
brand-primary = indigo-500
어디에 쓰는지 의미를 담은 별칭.
03 · Component
버튼 배경 = brand-primary
화면에서 실제로 사용.
Figma Variables

Primitive는 _primitive 컬렉션, Semantic은 semantic 컬렉션으로 분리. Semantic 베리어블의 값을 Primitive 베리어블에 alias(별칭 연결)로 묶는다.

확장성

브랜드 색을 바꿔도 Primitive 한 곳만 고치면 모든 화면이 따라온다. Semantic → Component 연쇄 갱신.

금지 사항

화면에서 Primitive 직접 사용 금지. 두께 600·700 사용 금지 (차분·프리미엄 톤). 과목색을 브랜드색으로 대체 금지.

text-secondary
